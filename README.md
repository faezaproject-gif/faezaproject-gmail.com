# Faeza Project

Website portfolio Faeza Project.

## Isi
- Website
- Multimedia
- Event Organizer
- Muslim Wear
- Portfolio
- Proses kerja
- Konsultasi WhatsApp
- PWA/offline cache

## Publikasi ke GitHub Pages
1. Upload seluruh isi folder project ke repository GitHub.
2. Pastikan `index.html` berada di root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch utama (`main` atau branch yang digunakan) dan folder `/ (root)`.
6. Simpan dan tunggu proses deployment selesai.

## Catatan
Nomor WhatsApp pada tombol konsultasi saat ini menggunakan nomor yang sudah ada di project. Jika nomor berubah, ganti semua URL `wa.me` di `index.html`.
